# Advanced Logger Examples

このディレクトリには`advanced_logger`パッケージの使用例が含まれています。

## 実行方法

```bash
dart run example/advanced_logger_example.dart
```

## 含まれる例

### グローバル関数の使用（推奨）
- `debugLog()`, `infoLog()`, `warningLog()`, `errorLog()`, `fatalLog()`
- エラー情報付きのログ出力
- JSON形式のデータを含むログ出力

### インスタンスベースの使用
- シングルトンパターンによるインスタンス取得
- 従来のメソッド呼び出し方式

### 実用的な使用例
- 関数の開始・終了ログ
- エラーハンドリング
- 条件に応じたログレベルの使い分け
- デバッグ情報の出力

## ベストプラクティス

1. **グローバル関数を優先的に使用**
   - `debugLog()`などのグローバル関数は、インスタンス管理が不要で簡潔です

2. **適切なログレベルの選択**
   - `debug`: 開発時のデバッグ情報
   - `info`: 通常の動作情報
   - `warning`: 注意が必要な状況
   - `error`: エラーが発生したが復旧可能
   - `fatal`: 致命的なエラー

3. **構造化データはJSON形式で出力**
   - `*WithJson`関数を使用して、オブジェクトを見やすく出力

4. **エラー情報を含める**
   - 例外が発生した場合は、エラーオブジェクトとスタックトレースを含める
